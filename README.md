# 重点药品支出异动解释

保存重点药品支出变化、比较口径和归因证据。

## 领域资料

仓库中的 `contracts/context.schema.json` 描述基础资料格式，`fixtures/context.json` 给出可公开使用的示例。代码库只负责读取与校验这些资料，业务服务可沿用相同标识和版本约定。

当前资料反映的事实包括：

- 重点监测药品支出减少约四百五十亿元
- 支出变化可能受多种因素影响
- 监管成效不能替代患者用药可及性判断

## 后台模块

- `src/snapshot.py`：冻结比较人群、药品口径、地区范围与观察窗口；口径一旦冻结不可修改，药品目录变化等调整只能生成新快照
- `src/sources.py`：结算、价格、供应、诊疗量、核查行动与患者服务反馈六类数据接入，以及（地区 × 期间）单元的覆盖核查
- `src/results.py`：只增不改的版本化结果；数据修订、跨月回补、药品目录变化与地区漏报补报都生成新版本，历史版本永远可查
- `src/privacy.py`：聚合阈值与公开材料检查，未达最小人数阈值的单元一律隐藏
- `src/attribution.py`：分析师提交彼此竞争的归因，每条归因标明证据强度与不确定性
- `src/signals.py`：就医中断信号检测，提示支出下降是否伴随取药受阻
- `src/report.py`：决策者视图，汇总下降位置、得到支持的解释、中断信号与口径变化影响

`contracts/snapshot.schema.json` 与 `contracts/hypothesis.schema.json` 描述快照与归因的资料格式，`fixtures/` 提供可公开使用的虚构示例。

## 分析规则

- 未覆盖的地区-期间单元只标记为缺失，绝不按零值计入汇总；变化只在基线与窗口均已覆盖的可比地区上计算
- 任何数据修订、跨月回补、目录变化或漏报补报都只能生成新版本结果，不得修改已发布版本
- 低于最小人数阈值的聚合单元在公开材料中隐藏，公开视图不含人数与明细标识，不得反推个人
- 支出下降伴随诊疗量下滑与患者反馈上升时生成就医中断信号；监管成效不能替代患者用药可及性判断
- 口径变化对汇总判断（如约四百五十亿元的下降）的影响单独分解为口径效应，不计入实际支出变化

## 本地校验

运行项目自带测试即可确认样例资料可读取，且领域标识与版本字段完整。所有示例均为虚构数据，不含真实个人信息、账号或访问凭据。
